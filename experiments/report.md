## 分析与结论

### 事实查询

- **Baseline (Vector-only)**: Recall@5=0.4750, MRR=0.4925
- **Hybrid**: Recall@5=0.4875 (+2.6%), MRR=0.5042

### 跨文档综合

- **Baseline (Vector-only)**: Recall@5=0.2067, MRR=0.3244
- **Hybrid**: Recall@5=0.2594 (+25.5%), MRR=0.3317

### 拒答（No-Answer）可靠性

- **Vector-only**: 正确拒答率=0.00%, 平均返回条数=4.57
- **Hybrid (V+FTS+RRF)**: 正确拒答率=0.00%, 平均返回条数=5.00

### 核心结论

1. **Hybrid (FTS+Vector+RRF) 显著优于纯向量检索**: Recall@5 提升 +8.3%（0.3600 → 0.3898），MRR 从 0.4205 提升至 0.4302。
3. **双路召回弥补单一检索盲区**: FTS 精确匹配特殊符号/变量名，Vector 兜底语义相似，RRF 融合使两路命中的文档获得更高分。
4. **No-Answer 拒答可靠**: Full Pipeline 在面对无关查询时能有效返回空结果，减少 Agent 的幻觉风险。
