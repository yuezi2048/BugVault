# Current Documentation

This directory is the home for current BugVault documentation.

- `CONTEXT.md` at the repository root is the authoritative domain glossary.
- Current architecture, specifications, decisions, and validation records belong here.
- [`codex-docs/`](../codex-docs/) contains historical documentation produced with Codex.
- [`reasonix-doc/`](../reasonix-doc/) contains historical development traces produced with Reasonix.

When historical documents conflict with the code or current documentation, use
the code and current `docs/` content as the source of truth.
